# CSS Fundamentals – FreeCodeCamp Exercises

This repository contains all the CSS exercises I completed while learning on FreeCodeCamp.

## 📚 About this project

The goal of this project is to practice and strengthen my understanding of CSS fundamentals through structured exercises and hands-on coding challenges.

These exercises helped me build a solid foundation in:
- CSS selectors
- Box model
- Flexbox
- Typography
- Colors and backgrounds
- Positioning
- Responsive design basics

## 📁 Project structure

Each folder contains exercises related to a specific CSS topic:

- selectors/ → CSS selectors and specificity
- box-model/ → margin, padding, border, width/height
- flexbox/ → flexbox layouts and alignment
- typography/ → fonts, text styling
- colors/ → color usage, gradients, backgrounds
- positioning/ → relative, absolute, fixed positioning
- responsive/ → basic responsive design exercises

## 🎯 Goals

- Understand and apply CSS fundamentals
- Practice building layouts from scratch
- Improve code organization and readability
- Prepare for real-world frontend projects
